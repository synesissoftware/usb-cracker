## From a source checkout

**usb-cracker** is a private project and is **not** published to
RubyGems.org.

```
bundle install
bundle exec rake test
```


## Install a local gem

```
./build_gem.sh
gem install --local usb_cracker-*.gem
```


## Using the CLI

```
usb-cracker --help
usb-cracker --version
```
