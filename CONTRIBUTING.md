## Scope

**usb-cracker** is a **private** Synesis Information Systems project.
External pull requests and public issue trackers are not applicable. Internal
changes should keep diffs local to the change, match existing indentation
(2 spaces in Ruby), and follow the Synesis markdown set (**README.md**,
**CHANGES.md**, **NEWS.md**, **TODO.md**, **INSTALL.md**,
**CONTRIBUTING.md**, **SECURITY.md**).
