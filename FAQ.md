# FAQs: <!-- omit in toc -->


## Q1: "How do I install this tool?"

From a private source checkout — see [INSTALL.md](./INSTALL.md). It is **not**
available via `gem install` from RubyGems.org.


## Q2: "Is this for cracking arbitrary USB drives?"

No. **usb-cracker** is for recovering forgotten suffixes on the operator's
**own** macOS software-encrypted volumes. It is not intended for third-party
devices.


## Q3: "Is this published on RubyGems or GitHub?"

No. **usb-cracker** is a private Synesis Information Systems project.
